# Note for teachers and event organisers

*Send this (edited as you like) to a teacher or organiser before a session that uses the Qublitz demos.*

---

The Qublitz demos your group will use (https://mvwf.github.io/qublitz/) count their use anonymously so the
Fitzpatrick Lab at Dartmouth can see which activities work and improve them. **No personal information is collected
from anyone:** no names, emails, accounts, cookies or identifiers, and nothing students type is sent. When students
answer the optional questions inside the games, the demos record only which choice was picked and whether it was
right, plus two optional 1–5 ratings.

We'll give you links ending in `?event=YOURCODE` so we can see how the session went as a group; the code labels the
session, not any student. If you'd prefer nothing to be sent at all, students can click "Opt out" at the bottom of any
page, or you can use the offline downloads, which never send anything. The full privacy notice is at
https://mvwf.github.io/qublitz/privacy.html. Questions: mattias.w.fitzpatrick@dartmouth.edu.
