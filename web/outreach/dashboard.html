      Questions by learning objective

      Share of answers that were right, per question, grouped under the objective it tests, with answers given inside the game and in the debrief shown apart. The tick is 50%. The most-picked wrong answer is the misconception signal.

      Where players stop

      Left: the place each visit ended (the last level or step the page reported), as a share of the visits that ended in this game; ▲ marks a stop hotspot from the Insights. Right: visit depth, the number of levels completed in one visit. Hover or use the table for how many started each level.

      Page versions

      Each visit records the version of the page it used: the date its files last changed and that commit (linked). Compare versions to see whether a change helped. Visits from copies the site did not build (a local server, a test run) carry no version and are left out;
