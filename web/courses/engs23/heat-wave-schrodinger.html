Three Equations, One Eigenbasis

Heat, wave, and Schrödinger all live on the same interval with the same walls, so they share one spatial operator and therefore one set of modes sin(nπx/L). Give all three the same starting shape and release them. What differs is only how each equation turns a spatial eigenvalue λn into motion in time. The clock below is set so the fundamental mode n = 1 has the same rate in all three panels, which makes the contrast between them the real content.

The one idea

shared spatial eigenproblem −d2φdx2 = λ φ, φ(0) = φ(L) = 0 ⇒ φn = √2L sin nπxL, λn = (nπL)2
heat — first order in t, real ∂tu = α ∂xxu ⇒ Tn(t) = e−αλnt (rate ∝ λn ∝ n2)
wave — second order in t, real ∂ttu = v2 ∂xxu ⇒ Tn(t) = cos(v√λn t) (ω ∝ √λn ∝ n)
Schrödinger — first order in t, the factor i iℏ ∂tΨ = −ℏ22m ∂xxΨ ⇒ Tn(t) = e−i(ℏλn/2m)t (ω ∝ λn ∝ n2)

Read the three right-hand sides together. Heat and Schrödinger carry the same n² spectrum because both are first order in time against the same operator, yet one is a real exponential that decays and the other is a complex exponential that only rotates. The single factor of i is the whole difference between irreversible smoothing and reversible unitary flow. The wave equation is second order in time, so it takes the square root of the eigenvalue and lands on ω ∝ n, the plain harmonic series of the guitar string.

The clock is shared, with one deliberate twist. Schrödinger phases spin as n², far faster than the wave’s n, so run at the same rate it would just blur. The Schrödinger rate control scales its clock down (default 0.3) to make the motion watchable. The time axis is arbitrary anyway. At rate 1 the packet would revive exactly when the wave reforms at t = 1, where the heat profile has also faded to e−1 of its fundamental with the high modes gone first.

Drag on the strip to sketch the shared starting shape. Ends pin to the walls.

Fourier components cn — drag the bars

Re cn — amplitude, felt by all three equations
Im cn — phase, changes Schrödinger only (this is momentum)

Drag a bar up or down to set that mode. Heat and wave are real equations, so they respond only to Re cn. Schrödinger carries the full complex amplitude cn = Re + i Im, so a sloped Im cn pattern gives the packet momentum and sends it moving. The bars show cn at t = 0 and hold still while the clock runs: each equation only multiplies mode n by its own Tn(t), so the modes never mix. Heat shrinks every |cn| (high n first), the wave swings each one between ±cn, and Schrödinger only turns its phase, so it alone keeps every |cn| fixed.
