🧹 ErrorSweeper find the errors you cannot see

Quantum error correction is a deduction game. You never look at the data qubits, because measuring them would destroy the quantum state. Instead, check qubits (ancillas) measure the parity of a few neighbours and light up when an odd number of them has an error. Read the lamps, guess where the errors are, and apply corrections until every lamp is off. Then the truth is revealed: if your correction and the errors form a closed loop, the logical qubit survived. If they stretch across the code, you just flipped the logical qubit. The physics is real: these are the rotated surface code, the toric code, and the Steane and Shor codes, under code-capacity noise.

    The physics

    Why lamps, not looking

    Measuring a data qubit would collapse the superposition the code protects. A stabilizer measurement only asks “is the parity of these qubits even?”, which every valid code state answers the same way, so it reveals errors without revealing the data. A Z⊗Z⊗Z⊗Z check flips sign when an odd number of its qubits suffered an X (bit-flip) error; an X⊗X⊗X⊗X check does the same for Z (phase-flip) errors; a Y error is both. That pattern of flipped checks is the syndrome.

    Why loops are harmless and strings are fatal

    After your correction the lamps are off, so errors plus corrections form chains with no loose ends. A closed chain that encloses a region (one you could shrink to nothing) is a product of checks (a stabilizer) and does nothing to the encoded qubit, which is why many different corrections can all be right (degeneracy). A chain that runs from one edge of the code to the opposite edge, or around the torus, is a logical operator: it flips the encoded qubit and no lamp can see it. The code distance d is the length of the shortest such chain, so a code can always fix up to ⌊(d − 1)/2⌋ errors.

    What this game leaves out

    Code-capacity noise: each round the checks are measured once and perfectly. Real hardware repeats the measurements many times, because the ancillas and the measurements make errors too, and decodes in space and time; that lowers the surface-code threshold to about 1%. The decoder here is exact minimum-weight matching for the surface, toric and repetition codes (greedy pairing when more than 16 lamps of one type are lit, which is rare here) and a minimum-weight search for the small codes; it decodes X and Z separately, so for Y errors it ignores their correlation.
